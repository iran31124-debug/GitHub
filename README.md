# مدیریت اقساط بیمه

اپلیکیشن فارسی و RTL برای ثبت، پیگیری و گزارش‌گیری اقساط بیمه.

## امکانات
- ورود با رمز عبور (رمز اولیه: 1234)
- تغییر رمز ورود
- داشبورد مالی
- ثبت، ویرایش و حذف قسط
- نام بیمه‌گذار، شماره تماس و شماره بیمه‌نامه
- ثبت مبلغ و تاریخ سررسید
- ثبت پرداخت
- جستجو بر اساس نام، تلفن یا بیمه‌نامه
- فهرست بیمه‌گذاران و بدهی هر شخص
- گزارش کل، دریافتی و بدهی
- ذخیره اطلاعات روی خود گوشی بدون نیاز به سرور
- GitHub Actions برای ساخت خودکار APK

## ساخت APK در GitHub
1. فایل‌های این پروژه را در ریشه repository قرار دهید.
2. به بخش Actions بروید.
3. Workflow با نام Build APK را اجرا کنید.
4. بعد از موفقیت، از Artifacts فایل `BimehInstallmentManager-debug` را دریافت کنید.

## نسخه بعدی قابل توسعه
برای همگام‌سازی چند گوشی، پشتیبان‌گیری ابری، کاربران چندگانه، اعلان سررسید و تقویم شمسی واقعی، می‌توان Supabase را به همین ساختار اضافه کرد.
