# مدیریت اقساط بیمه

نسخه Android فارسی برای ثبت بیمه‌گذار، بیمه‌نامه، اقساط، سررسید، پرداخت و گزارش مالی.

## ساخت APK با GitHub Actions

1. تمام فایل‌های این پوشه را در repository خود در شاخه `main` قرار دهید.
2. از بخش **Actions**، workflow با نام **Build APK** را اجرا کنید؛ یا یک commit/push انجام دهید.
3. پس از موفقیت، در صفحه اجرای workflow بخش **Artifacts** فایل `BimehInstallmentManager-debug` قرار می‌گیرد.
4. ZIP آرتیفکت را دانلود و `app-debug.apk` را روی گوشی نصب کنید.

> این نسخه اطلاعات را فعلاً روی خود گوشی ذخیره می‌کند. برای همگام‌سازی چند گوشی، مرحله بعدی اتصال Supabase است.
