# مدیریت اقساط بیمه — Professional 3.0

نسخه فارسی و RTL با مدیریت بیمه‌گذاران، بیمه‌نامه‌ها، اقساط، پرداخت، گزارش و پشتیبان‌گیری.

## امکانات جدید
- رمز اولیه در اولین اجرا
- ذخیره‌سازی آفلاین
- همگام‌سازی ابری با Supabase
- پشتیبان JSON
- داشبورد مالی و گزارش بدهی
- ساخت APK با GitHub Actions

## Backend
این نسخه به پروژه Supabase متصل شده و از جدول `cloud_snapshots` برای پشتیبان ابری استفاده می‌کند. داده محلی همچنان منبع کار آفلاین است و دکمه «همگام‌سازی ابری» نسخه JSON فعلی را در فضای ابری ذخیره می‌کند.

## Build
در GitHub فایل‌های پروژه را در ریشه repository قرار دهید و از Actions، workflow با نام `Build APK` را اجرا کنید.

> توجه: این محیط Android SDK ندارد؛ APK اینجا اجرا/کامپایل نشده و Build نهایی باید در GitHub Actions انجام شود.
